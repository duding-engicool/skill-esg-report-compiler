## TCFD框架概览

TCFD（Task Force on Climate-related Financial Disclosures）于2017年发布气候相关财务信息披露框架，旨在帮助投资者、贷款人和保险公司评估气候相关风险与机遇。

### 核心原则
- 提供有价值的决策信息
- 与现有报告框架兼容
- 关注实质性与前瞻性信息
- 保证信息可靠性

## 四大核心要素

### 1. 公司治理（Governance）

披露内容：
- 董事会对气候相关风险与机遇的监督
- 管理层在评估和管理气候相关风险与机遇中的角色
- 气候相关治理机构的设置与报告路径

建议披露：
```
示例披露结构：
公司董事会下设ESG委员会，负责监督气候相关战略。
委员会每季度审查气候风险评估报告，并就减排目标
向董事会提出建议。
```

### 2. 战略（Strategy）

披露内容：
- 组织识别的气候相关风险与机遇
- 风险与机遇对业务、战略和财务规划的影响
- 不同气候情景下的战略韧性分析

关键气候场景：
| 场景类型 | 升温路径 | 特征描述 |
|----------|----------|----------|
| 快速转型 | 1.5-2°C | 政策干预早、碳价高、技术突破 |
| 延迟行动 | 2-3°C | 政策逐步收紧、过渡风险显著 |
| 高排放路径 | >3°C | 物理风险突出、转型风险较低 |

### 3. 风险管理（Risk Management）

披露内容：
- 气候相关风险的识别与评估流程
- 气候相关风险的管理流程
- 气候相关风险如何融入整体风险管理

风险分类：
- **转型风险**：政策与法规风险、技术风险、市场风险、声誉风险
- **物理风险**：急性风险（极端天气事件）、慢性风险（气温上升、海平面上升）

### 4. 指标与目标（Metrics and Targets）

披露内容：
- 用于评估和管理气候相关风险与机遇的指标
- 范围1、2、3温室气体排放
- 气候相关目标及表现

## 指标与目标

### 气候关键指标（TCFD推荐）

| 类别 | 指标 | 计量单位 | 本Skill对应 |
|------|------|----------|-------------|
| 温室气体排放 | 范围1排放 | 吨CO2e | E1 |
| 温室气体排放 | 范围2排放 | 吨CO2e | E1 |
| 温室气体排放 | 范围3排放 | 吨CO2e | E1 |
| 转型风险 | 碳价格 | 元/吨CO2e | - |
| 物理风险 | 水资源压力 | % | E3 |
| 目标设定 | 减排目标 | % | G4 |

### 目标设定建议
1. **短期目标**：1-3年，与运营改进相关
2. **中期目标**：3-10年，与资本支出周期一致
3. **长期目标**：10年以上，与行业脱碳路径一致

## 与ESG Skill的关联

### 数据采集整合
本Skill的环境维度数据采集直接支持TCFD的"指标与目标"披露：

```
用户输入 → esg_data_collector → TCFD指标映射 → ESG报告
```

### 关键映射关系
- **E1（温室气体排放）** → TCFD范围1/2排放
- **E2（能源消耗）** → TCFD能源管理
- **G4（目标达成率）** → TCFD减排目标进展

### 报告输出
使用 `esg_exporter.py` 导出时，可特别关注TCFD章节的生成，确保包含：
1. 治理结构说明
2. 气候风险评估摘要
3. 排放指标及趋势
4. 减排目标与进展
