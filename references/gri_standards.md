## GRI标准概览

GRI（Global Reporting Initiative）是最广泛使用的可持续发展报告框架，发布了GRI Standards作为报告编制标准。

### 2021年后GRI标准结构
```
GRI Standards
├── GRI 1: 基础（Foundation）
├── GRI 2: 一般披露（General Disclosures）
├── GRI 3: 实质性议题（Material Topics）
└── GRI Standards by Topic
    ├── GRI 201: 经济绩效
    ├── GRI 205: 反腐败
    ├── GRI 302: 能源
    ├── GRI 303: 水资源和污水
    ├── GRI 305: 排放
    ├── GRI 306: 废弃物
    ├── GRI 401: 雇佣
    ├── GRI 403: 职业健康与安全
    ├── GRI 404: 培训和教育
    ├── GRI 405: 多元化与平等机会
    └── GRI 205: 反腐败
```

## GRI通用标准

### GRI 2 - 一般披露要求

| 披露项 | 内容要求 |
|--------|----------|
| 组织基本信息 | 名称、所有权结构、法律形式、总部地址等 |
| 报告实务 | 报告周期、报告联系点、报告边界等 |
| 治理结构 | 最高治理机构组成、委员会设置、ESG职责分工 |
| 战略与政策 | ESG承诺、方针、政策、尽职调查流程 |
| 利益相关方参与 | 识别方式、参与频率、议题反馈机制 |

## 报告编制要点

### 实质性议题识别流程
1. 识别利益相关方及其关注点
2. 评估ESG议题的实际与潜在影响
3. 确定实质性议题矩阵
4. 验证并确认实质性议题清单

### 数据质量保障
- 建立内部数据采集流程
- 设置数据验证机制
- 记录数据来源与计算方法
- 定期审计关键数据

### 报告边界设定
- 明确纳入报告的运营实体
- 说明数据收集范围
- 披露排除项及理由
